# TR VIDEO DOWNLOADER

Site gratuito com interface preta e azul neon para TikTok, Instagram e Pinterest.

## Publicar no GitHub Pages

Em Settings > Pages, escolha Deploy from a branch, branch main e pasta / (root). Salve e aguarde a publicação.

Endereço esperado: https://robinhodlx7-code.github.io/tr-video-downloader/

## Estado atual

Esta versão é apenas a interface e **ainda não baixa vídeos**. O GitHub Pages não executa um servidor de downloads. É necessário conectar um backend próprio, com proteção contra abuso, e respeitar os direitos dos autores e as restrições das plataformas. Não é possível garantir HD nem arquivos sem marca d'água.
